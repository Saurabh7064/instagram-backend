# Kafka Learner Progress

Artifact readiness lives in the [backlog](./learning-backlog.md). This file records what the learner demonstrated.

- `NOT_ASSESSED`: no checkpoint attempt recorded.
- `LEARNING`: an attempt exists with a specific unresolved point.
- `UNDERSTOOD`: a plain-language explanation, correct prediction, and checkpoint answers are recorded.
- `RETAINED`: the learner repeats the explanation and diagnoses a related failure at a later review without notes.

Commands succeeding or an assistant preparing lessons never upgrades these statuses. In chat, teach only one micro-lesson and wait for the learner's attempt. If confused, return to its prerequisite and introduce no new terms.

## Evidence entry format

Record the date, part ID, learner's own explanation, prediction and result, checkpoint attempt, diagnosed failure if applicable, one remaining confusion, and the exact prerequisite to revisit. Preserve the learner's words where practical. Do not fill these fields with a model answer presented by the assistant.
