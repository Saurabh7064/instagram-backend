# Integrated DevOps Learner Progress

This tracker records demonstrated understanding, separately from project implementation.

## Status legend

- `NOT_ASSESSED` — material may exist, but no specific checkpoint has been attempted.
- `LEARNING` — the checkpoint started and at least one misunderstanding or missing prerequisite remains.
- `DEMONSTRATED` — the learner explained the problem, predicted behavior, and diagnosed one controlled failure.
- `RETAINED` — the key idea was recalled and applied again in a later session.
- `NEEDS_REVIEW` — a later check exposed a gap; return to the smallest relevant micro-lesson.

Do not infer a learner status from a successful command, completed backlog item, or self-report such as “kind of understand.” Map evidence to a specific lesson checkpoint.

## Evidence required for `DEMONSTRATED`

For the specific stage, record all three:

1. the learner's plain-language explanation of the problem and solution;
2. a prediction made before an action;
3. diagnosis and recovery of one controlled failure using evidence.

For `RETAINED`, add a later date and a fresh example rather than repeating the same question verbatim.
