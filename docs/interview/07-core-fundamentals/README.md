# Core Backend Fundamentals

Study these through likely interview questions and system-design decisions.

## Priority areas

- SQL: joins, aggregation, indexes, query plans, transactions, isolation, locks
- Data modeling: normalization, denormalization, relational vs document/key-value stores
- Networking: DNS, TCP, TLS, HTTP, proxies, load balancers, timeouts
- Operating systems: processes, threads, memory, files, scheduling, sockets
- APIs: REST semantics, RPC, pagination, compatibility, authentication, rate limiting
- Security: least privilege, secrets, injection, XSS/CSRF basics, threat modeling
- Reliability: timeouts, retries with backoff, circuit breakers, bulkheads, idempotency
- Observability: structured logs, metrics, traces, SLOs, alert quality

## Readiness check

For each topic, answer: What problem does it solve? How does it work at a useful level? What goes wrong? How would I observe the failure? Where have I used or seen it?
