# Cloud, Messaging, and DevOps

Keep this role-specific. Increase depth only when it appears in a target job description or in your own resume claims.

## AWS

- IAM and least privilege
- VPC basics, subnets, routing, security groups, and load balancing
- EC2/container/serverless trade-offs
- S3, RDS, DynamoDB, caching, and queues
- Availability, scaling, observability, cost, and disaster recovery

## Kafka and messaging

- Topic, partition, broker, producer, and consumer group
- Ordering and partition-key choices
- Offsets, rebalancing, delivery semantics, and duplicate processing
- Retry topics, dead-letter queues, idempotent consumers, and schema evolution
- Kafka vs SQS/SNS or RabbitMQ

## Kubernetes and delivery

- Pod, Deployment, Service, ingress, and configuration
- Readiness/liveness, resources, autoscaling, and rolling deployments
- Debugging a failed deployment
- CI/CD, artifact promotion, rollback, infrastructure ownership, and secrets

## Stop rule

Stop when you can explain the topic, discuss a real example, diagnose a common failure, and compare one alternative. Do not turn interview preparation into certification study.
