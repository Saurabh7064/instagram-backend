# Low-Level Design and Machine Coding

This is a commonly missed interview category for experienced Java engineers. It tests object modeling, maintainability, extensibility, and coding judgment rather than distributed architecture.

## Topics

- Requirements and use-case modeling
- Entities, value objects, interfaces, and composition
- SOLID principles used pragmatically
- Design patterns chosen because a requirement needs them
- State transitions, validation, errors, concurrency, and persistence boundaries
- Testable code and incremental evolution

## Practice problems

- Parking lot
- Elevator system
- Library or inventory system
- Vending machine
- Splitwise-style expense sharing
- Meeting-room scheduler
- Notification-rule engine
- In-memory cache with eviction
