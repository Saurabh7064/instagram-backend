# Day 1 — Coding Baseline and Arrays + Hash Maps

- Date: 2026-10-04
- Status: `LEARNING`
- Primary lesson: [Arrays and Hash Maps in Java](../01-coding/lessons/01-arrays-hash-maps.md)

## Why this is first

Arrays and hash-based lookup appear directly in many interviews and underneath later patterns such as sliding windows, prefix sums, graph adjacency structures, caching, deduplication, and frequency counting. A timed baseline today also prevents the study plan from being based on guessed strengths and weaknesses.

## Today’s outcome

By the end of the session, you should be able to:

1. Recognize when repeated searching can be replaced with remembered information.
2. Choose among `HashSet`, `HashMap`, and a direct array/index representation.
3. State the invariant before writing Java code.
4. Explain average and worst-case behavior without saying only “HashMap is O(1).”
5. Complete one unseen or unrehearsed medium problem in 35 minutes and record evidence honestly.

## Three-hour schedule

### Block 1 — Baseline before studying (40 minutes)

- Spend 5 minutes reading the baseline prompt and asking clarifying questions.
- Use a strict 30-minute timer to solve it in Java without hints.
- Spend 5 minutes recording where time went: recognition, approach, implementation, debugging, testing, or explanation.

Do not read the solution section in the primary lesson before attempting the baseline.

### Break (10 minutes)

Leave the screen, hydrate, and do not inspect a solution.

### Block 2 — Deep concept lesson (65 minutes)

- Learn the array-versus-hash mental model.
- Practice the six common transformations.
- Walk through the complement pattern.
- Review the Java-specific correctness traps.
- Answer Checkpoints 1–5 aloud before revealing their answers.

### Break (10 minutes)

### Block 3 — Deliberate practice (40 minutes)

- Implement the guided problem from a blank editor.
- Complete one independent problem without copying the template.
- Test empty, minimal, duplicate, negative, and boundary cases where applicable.

### Block 4 — Teach-back and evidence (15 minutes)

- Answer Checkpoints 6–8 aloud.
- Explain the pattern in two minutes as if speaking to an interviewer.
- Update the problem log and spaced-review queue.
- Schedule reviews for 2026-10-05, 2026-10-11, and 2026-11-04.
