# Mock Interviews

Mocks turn knowledge into interview performance. Start before you feel ready.

## Cadence

- October: one mock or recorded session per week.
- November: two per week, alternating coding and system design.
- December onward: simulate complete interview loops and add behavioral rounds.

## Feedback categories

Track requirements/clarification, structure, correctness, communication, testing, trade-offs, senior judgment, pacing, and recovery after a mistake. Convert each repeated weakness into a time-boxed exercise in the relevant folder.
