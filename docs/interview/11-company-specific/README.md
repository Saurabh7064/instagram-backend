# Company-Specific Preparation

Create one note per active interview process. Research only enough to tailor preparation and ask informed questions.

Choose J (Java/Spring depth), A (algorithms + design), P (practical backend coding), or L (lead/architect emphasis) using the [curated interview guide](../curated-interview-guide.md). Classify the confirmed process rather than assuming that every team in a company or industry uses the same interview.

## Company note template

- Company / team / role:
- Job-description link and copied key requirements:
- Interview stages and dates:
- Confirmed profile and evidence from recruiter/interview guide:
- Coding format, SQL expectations, Java version, tooling/AI rules, and round durations:
- Skills emphasized repeatedly:
- Likely coding patterns:
- Likely design domain:
- Resume stories to use:
- Product and architecture hypotheses:
- Why this role:
- Questions for recruiter, manager, and engineers:
- Interview feedback and follow-ups:

Do not rely on leaked exact questions. Use reported interview formats as hints and keep preparation transferable.
