# System Design Morning Print Pack

This directory is intentionally different from the detailed lesson format. It contains dense, print-first revision material for a short daily review.

## Files

- `system-design-morning-cheat-sheet.pdf`: printable A4 booklet with 132 compact questions and answers.
- `system-design-concepts-with-examples.pdf`: printable A4 handbook with 120 substantial concept explanations and concrete examples.
- `system-design-scenario-drills.pdf`: printable A4 booklet with 200 production-meeting scenarios, exact interview questions, and spoken-answer models.
- `system-design-learning-tracker.pdf`: printable A4 progress tracker for all 380 concepts in `index.md`.
- `index.md`: master numbered coverage index for the 380 concepts.
- `system-design-morning-cheat-sheet.md`: editable source for the question bank.
- `system-design-concepts-with-examples.md`: editable source for the concept handbook.
- `system-design-scenario-drills.md`: editable source for the 200-scenario question bank.
- `system-design-learning-tracker.md`: editable one-row-per-concept digital tracker generated from `index.md`.
- `generate_print_pack.py`: deterministic PDF generator.
- `generate_concept_guide.py`: deterministic concept-handbook PDF generator.
- `generate_scenario_drills.py`: deterministic scenario-booklet PDF generator.

## Suggested morning routine

1. Pick five concepts from the master tracker, use the concept handbook for deeper explanations, or choose two scenario drills.
2. Cover each answer and speak for 60-90 seconds as if you were in a technical meeting.
3. Compare with the printed answer and mark `Learned` only when the core decision is correct.
4. Revisit after one day and seven days.
5. Mark `Explain` only when you can state the core idea, trade-off, and one failure without looking.

Artifact readiness does not imply understanding. The tracker starts blank on purpose.
