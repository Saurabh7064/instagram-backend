# LeetCode Micro-Lesson Index

This is the navigation map for future coding practice. Each row will become one focused lesson directory with one primary idea, one problem, one editable Java program, and one reference solution—but only when that lesson is activated.

## Status legend

- `TODO`: not started
- `LEARNING`: the single active lesson
- `DEFERRED`: intentionally postponed without receiving mastery credit
- `PRACTICING`: initial lesson passed; spaced practice remains
- `INTERVIEW_READY`: unseen variation solved and explained within the target time
- `RETAINED`: skill rechecked successfully after a longer interval

## How this reaches the 120–150 problem target

The core path contains 72 primary problems. Reviews, unseen variations, mock-interview problems, and company-specific additions supply the remaining practice. A problem is counted as mastered only after a later successful retrieval, not after reading its solution.

## Activation rule

When a lesson becomes active:

1. Create one focused lesson directory.
2. Create one IntelliJ-runnable practice class and one reference class.
3. Add 2–3 checkpoints and explicit stop/go criteria.
4. Change exactly one lesson to `LEARNING`.
5. Record prior lessons as `PRACTICING`, `DEFERRED`, or another honest status—never automatically `DONE`.
