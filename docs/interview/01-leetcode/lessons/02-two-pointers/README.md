# Module 02 — Two Pointers

Two pointers replace repeated pair comparisons when the data order or boundary relationship tells us which candidate can be discarded safely.

## What this module teaches

- move inward while preserving a clear invariant;
- use sorted order to eliminate impossible candidates;
- prove why moving one boundary cannot discard the answer;
- extend a two-value search to unique three-value combinations.
