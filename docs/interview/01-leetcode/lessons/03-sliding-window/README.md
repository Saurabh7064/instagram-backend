# Module 03 — Sliding Window

A sliding window reuses information from a neighboring contiguous range instead of recomputing the range from scratch.

## What this module teaches

- maintain a fixed-size aggregate by removing one value and adding one value;
- expand and shrink variable-size windows while preserving an invariant;
- track counts and constraints only for the active range;
- distinguish contiguous-range problems from arbitrary subset problems.
